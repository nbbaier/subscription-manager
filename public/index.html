Browser Extension

Automatically track time spent on subscription websites

Setup Instructions

  1. Navigate to the extension folder in the project
  2. Build the TypeScript files: bun build background.ts content.ts --outdir=. --target=browser
  3. Open Chrome and go to chrome://extensions/
  4. Enable "Developer mode" (toggle in top right)
  5. Click "Load unpacked" and select the extension folder
  6. Add domain mappings above to start tracking

The extension tracks time spent on mapped domains and syncs usage data every 5 minutes. Usage is only tracked when the page is visible and you're actively using it.
